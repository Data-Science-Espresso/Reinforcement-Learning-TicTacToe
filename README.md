# Q-Learning Agent for Tic Tac Toe

A Q-learning agent that learns to play Tic Tac Toe from scratch — no rules, no neural network, just trial, error and reward.

Code for the article [Reinforcement Learning Made Simple: Build a Q-Learning Agent in Python](https://towardsdatascience.com/reinforcement-learning-made-simple-build-a-q-learning-agent-in-python/) on Towards Data Science.

## Setup

```powershell
python -m venv RLTicTacToe
.\RLTicTacToe\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Run

```powershell
python TicTacToeRL.py
```

The agent plays 10,000 games against a random opponent. You will see the results in the terminal, then a learning curve, and after closing that window an example board.
